# FlameLang 0.2.0-rc.1

Versão experimental para Windows x64. Escolha o instalador `…setup.exe` ou o ZIP `…portable.zip`.
Leia `LEIA-ME.txt`. O ZIP de código-fonte gerado pelo GitHub não é um instalador.

Inclui editor, condições, ciclos, funções e leitura de CSV.
Os resultados de instalação, execução e desinstalação constam da execução de Actions associada.
Testes automáticos em Windows não equivalem a validação científica dos indicadores.
Linux e macOS não testados. Executáveis sem assinatura digital.
